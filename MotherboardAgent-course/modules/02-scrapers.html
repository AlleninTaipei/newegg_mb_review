The Web Scrapers

How a Python script reads a shopping website like a robot detective.

A browser, minus the human

When you visit Newegg in your browser, here's what actually happens: your browser sends a HTTP request to Newegg's server, the server sends back an HTML page, and your browser renders it visually.

The scraper does the first part — sending the request and receiving HTML — but skips the visual part entirely. Instead, it reads the HTML text and extracts just the data it needs: product names, prices, ratings.

🧑

Loads page → sees pretty visuals → reads prices with eyes

🤖

🎭
The scraper pretends to be a browser

The scraper sets a User-Agent header — a label that tells the server what kind of software is making the request. It uses a real Chrome browser's User-Agent string so Newegg treats it like a regular visitor, not a bot.

Knowing where to look

Before the scraper visits a single page, it needs to know which brands to search for and which URLs to construct. Newegg uses a filter system based on "N-values" — numeric codes that represent brands in their catalog.

CODE 
# Newegg N-values (discovered from filter sidebar JSON)
MOTHERBOARD_N = 100006654
BRANDS = {
    "ASRock":  {"n_val": 50001944, "max_pages": 3},
    "ASUS":    {"n_val": 50001315, "max_pages": 5},
    "MSI":     {"n_val": 50001312, "max_pages": 5},
    "Gigabyte":{"n_val": 50001314, "max_pages": 5},
}
PLAIN ENGLISH

This is a comment — a note to humans, ignored by the computer. It explains where these numbers came from.

100006654 is Newegg's internal code for "show me all motherboards" (AMD + Intel combined).

BRANDS is a dictionary — a lookup table. The brand name is the key; the value is another small table with that brand's details.

ASRock's Newegg brand code is 50001944. Only scrape up to 3 pages for ASRock.

ASUS, MSI, Gigabyte each have their own brand codes and get 5 pages scraped each — they have larger catalogs.

The closing brace ends the BRANDS dictionary.

Parsing HTML: reading the page like a map

Once the scraper downloads the HTML text of a Newegg page, it needs to find the product listings inside it. This is where BeautifulSoup comes in. It turns the raw HTML into a tree you can navigate.

CODE 
soup  = BeautifulSoup(resp.text, "lxml")
items = soup.select(".item-container")
if not items:
    print(f"  [{brand}] No items found – stopping.")
    break
PLAIN ENGLISH

Parse the HTML text of the response into a navigable structure called "soup." Use lxml as the parsing engine — it's fast.

Find all HTML elements with the CSS class "item-container" — this is the CSS class Newegg uses for each product card on a listing page.

If the list is empty, nothing was found on this page.

Print a message saying no items were found for this brand.

Stop the scraping loop — no more pages to process.

🔍
CSS classes as treasure map coordinates

Web developers use CSS classes to style groups of elements. Scrapers exploit this: if every product card has class="item-container", you can locate all products at once with .select(".item-container").

The scraper is polite on purpose

The scraper deliberately pauses between requests. This isn't inefficiency — it's courtesy. A scraper that hammers a server with hundreds of requests per second looks like a DDoS attack and will get your IP blocked. Watch the scraper and Newegg discuss this:

Extracting meaning from a product name

Newegg doesn't have separate database fields for "socket" or "chipset." That information is hidden inside the product name: "ASRock X870E Nova WiFi ATX AM5 Motherboard". The scraper reads the name and infers the specs using pattern matching.

CODE 
def parse_chipset(name: str) -> str:
    u = name.upper()
    for cs in [
        "X870E", "X870", "X670E", "Z890", "B860",
    ]:
        if cs in u:
            return cs
    return "Unknown"
PLAIN ENGLISH

Define a function called parse_chipset that takes a product name as input and returns a string (the chipset name).

Convert the name to uppercase so "x870e" and "X870E" both match — case-insensitive search.

Loop through a list of known chipset names in order, most specific first. (X870E before X870, so "X870E Nova" doesn't accidentally return just "X870".)

If this chipset name appears anywhere in the uppercase product name...

Return it immediately — we found it!

If no chipset name matched, return "Unknown" — better to admit ignorance than guess wrong.

🧩
Order matters: most specific first

The list checks "X870E" before "X870." If you reversed this order, "X870E Nova WiFi" would match "X870" first and return the wrong answer. This "most specific first" trick prevents false positives and is a common pattern in parsing logic.
