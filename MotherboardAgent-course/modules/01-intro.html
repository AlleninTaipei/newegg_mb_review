Your Market Intelligence Robot

One command. Three countries. Your inbox. Here's what actually happens.

Imagine waking up to a motherboard report

Every morning, three markets' worth of motherboard data — prices, ratings, store counts — lands in your inbox as a beautiful interactive dashboard. You didn't click anything. You didn't open a browser. It just appeared.

That's what MotherboardAgent does. It's a pipeline that runs three independent missions in parallel — one for the US (Newegg), one for Japan (Kakaku.com), and one for Korea (Danawa) — each ending with a detailed HTML report delivered to your inbox.

Why three separate programs instead of one?

Each region runs independently so a failure in Japan (say, Kakaku blocks the scraper) doesn't stop the US report from being sent. Isolation = resilience. This is a classic architectural pattern called decoupling — systems that don't share state can fail independently.

Meet the cast of files

Nine Python scripts, three JSON data files, three HTML dashboards. Everything is generated — nothing is hand-written except the scripts themselves.

🔑
The .env file is a secrets locker

Your email password and sender address live in a file called .env — and it's listed in .gitignore so it's never accidentally uploaded to GitHub. This pattern of separating secrets from code is a fundamental security practice.
